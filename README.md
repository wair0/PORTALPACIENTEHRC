# Portal Paciente HRC

App Android nativa (Kotlin + WebView) para el Portal del Paciente del Hospital Ramón Carrillo.

## Características

- WebView embebido con el portal oficial `https://tws.sanluis.gob.ar`
- Tema visual propio (CSS inyectado)
- Navegación nativa (drawer + bottom nav)
- Manejo de sesión y cookies

## Build

```bash
./gradlew assembleDebug
```

Requiere JDK 17.
